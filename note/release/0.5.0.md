# v0.5.0 开源首发布（2026-10-24）

首个公开发布版本，对应比赛交付的工程验证版。

## 新增

- MIT LICENSE 文件（此前 README 已声明但文件缺失）
- GitHub Actions CI：Ubuntu + Windows × Python 3.11，`ruff --select F,E9` 错误级门禁 + 全量 pytest
- `.gitattributes` 统一换行符（仓库 LF，PowerShell/bat 脚本 CRLF）
- `note/` 工作要点归档目录与开源发布调研报告

## 修复

- `test_project_finding_queue_clusters_completed_task_results` 在 Windows 上因时钟分辨率（约 15ms）产生相同时间戳导致的排序不稳定，改用显式时间戳
- pyproject.toml / README / 进度报告中的 `yourusername` 占位仓库链接替换为实际仓库地址
- generate_docx.py 两处未使用导入（F401）

## 已知限制

- tree-sitter-language-pack 首次使用需从 GitHub 下载解析器，受限网络下 TypeScript AST 审计通道降级
- 真实项目召回率/误报率尚无完整量化基准；LLM 深度验证仍不稳定，证据不足时结论保守保留 `needs_evidence`
- 前端部分遗留页面会回退到演示数据；任务依赖 FastAPI 进程内后台任务，服务重启会中断运行中的审计
- 代码风格债约 3200 条（py311 现代化为主），按路线图分批清偿，见 `note/research/`
