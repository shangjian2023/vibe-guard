# v0.6.0（2026-10-26）

聚焦两项 P0：离线可用性与 VAmPI 短板召回。

## 新增

- **tree-sitter 离线韧性**：新增 `core/languages/tree_sitter_gateway` 统一网关
  - 解析器下载失败按语言负缓存，不再逐文件重复退避阻塞审计
  - `VIBE_SEC_TREE_SITTER_CACHE` 指定共享缓存目录，支持离线分发与多项目复用
  - `VIBE_SEC_DISABLE_TREE_SITTER=1` 立即跳过全部 AST 通道，平台降级到文本/正则分析
  - `vibe-sec doctor` 报告 `tree_sitter` 就绪段；`vibe-sec setup` 自动预热解析器
- **审计召回**（对应 `docs/VAMPI_TEST_REPORT.md` 的短板项）：
  - SQL 注入补齐两类形态：调用外字符串拼接（`q = "...WHERE x = " + input`）、占位符中置 % 格式化（`"... = %s" % id`），此前仅覆盖 f-string 与 execute 内联拼接
  - 新增 `mass_assignment` 检测：admin/role 等特权字段直接取自请求数据
  - 新增 `plaintext_password_comparison` 检测：与存储凭据对象（`x.password`）的 `==` 比对
- 两类新漏洞类型接入 `STATIC_CONFIRMABLE` 验证白名单与 RemediationProfile 整改画像
- 回归测试 16 个新增（网关 9 + 召回 7），VAmPI 风格端到端召回 4/4，安全写法零误报

## 修复

- `protocol_analysis` / `semantic_typescript` 两个调用点此前未捕获 DownloadError，受限网络下 MCP TypeScript 审计与语义索引通道会直接崩溃，现统一走网关降级
- 移除 `作品简介.md` 中的个人联系方式（含 git 历史重写清理）

## 行为变化

- `vibe-sec setup`（非 dry-run）会附带 `tree_sitter_warmup` 结果，下载失败不阻塞镜像安装
- CI 测试矩阵在解析器不可获得时自动跳过两个真实 AST 用例（在线环境照常执行）

## 已知限制（不变）

- 真实项目召回率/误报率尚无完整量化基准；LLM 深度验证仍不稳定，证据不足时保守保留 `needs_evidence`
- IDOR/Debug 端点暴露等需深度语义理解的漏洞类型仍未覆盖，见 `note/research/` 路线图
